곳간 사용 가이드

지출결의서 작성 규칙과 예산 확인 방법

1. 지출결의서 쓰는 방법 (가장 중요)

아마란스에서 지출결의서를 기안할 때, 제목 맨 끝에 예산코드를 대괄호로 붙입니다. 예산코드는 [예산마스터] 탭에서 내 부서 항목을 검색해 확인합니다.

✅ 큐어젯 실장 세미나 대관료 지급의 건 [DOM-001]
✅ 7월 인스타그램 인플루언서 비용 [CLM-001]
✅ 큐어젯 프로 노즐 금형 제작비 [RND-CJP-003] (연구소·디자인은 제품 코드 포함)
❌ 세미나 대관료 지급의 건 (코드 없음 — 어느 예산에서 나가는지 알 수 없음)
  • 부서 코드: 연구소_선행연구 PRE · 연구소_연구개발 RND · C-Labs_마케팅 CLM · C-Labs_디자인 CLD · MA · 경영관리부문 MGT · 국내영업 DOM · 글로벌사업 GLB · 생산품질부문 PQC · 인허가 RA · 해외영업 OVS
  • 연구소(PRE·RND)와 C-Labs_디자인(CLD)은 코드 가운데에 제품 구분이 들어갑니다: BJ 부스터젯 · CJ 큐어젯 · CJP 큐어젯 프로 · HC 홈케어 · HP 핸드피스 · NZ 노즐 · RC 리클락 · PAT 특허 · COM 공통 — 예: PRE-BJ-001, CLD-CJ-002. 나머지 부서는 기존처럼 MGT-001 형식입니다.
  • 예전 형식(PRE-001)으로 적어도 자동으로 새 코드로 변환되지만, 새 기안부터는 새 코드를 써주세요.
  • 해당하는 예산 항목이 없는 새로운 지출이면 — 먼저 우리 부서의 기존 항목 중 가장 가까운 코드를 쓰고 재경팀에 알립니다. 예산 총액은 부서별로 승인된 값이라 항목을 새로 만들수록 통제가 어려워집니다. 기존 항목으로 담을 수 없는 성격이면 대표이사 기안으로 신규 예산코드 승인을 받은 뒤 재경팀이 코드를 만듭니다. 코드 없이 상신하면 항목별 집계에서 빠집니다.

2. 내 부서 예산 확인

  • [대시보드] — 부서 카드에서 집행률·잔액 확인, 카드를 누르면 계정별·항목별 세부
  • [월별] — 월별 지출 추이와 계정별 월 지출
  • [예산마스터] — 전체 예산 항목과 코드 목록

3. 예산 알림

각 예산코드의 집행률이 50% · 80% · 90% · 100%를 넘을 때마다 해당 부서 등록 사용자에게 메일이 발송됩니다. 100% 초과 시에는 추가 집행 전에 재경팀과 협의하세요.

4. 회계 처리 규칙

  • 지급임차료 — 전사 임차료는 경영관리부문 예산으로 통일
  • 자기계발비 — 경영관리부문 복리후생비로 처리
  • 원재료비 — 매출원가로 분류되어 판관비 집계에서 제외
  • 연구소 투자비(금형 등) — 예산에서는 집행 시 차감, 판관비에는 5년(60개월) 정액 상각으로 인식
  • 집행은 결재 종결 기준, 월 기준은 기안일, 반려·보류 건은 집계 제외

5. 접속과 로그인

  1. 사내 포털(bazbio.github.io) → 곳간 카드, 또는 휴대폰에서 홈 화면에 추가해 앱으로 사용
  2. 등록된 회사 이메일을 입력하면 인증번호 6자리가 그 메일로 옵니다. 비밀번호는 없고, 한 번 로그인하면 90일 유지됩니다
  3. 부서 계정은 자기 부서 예산·지출만 표시됩니다. 계정 등록·부서 변경은 관리자에게 요청
