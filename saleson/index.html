SalesON 사용 가이드
① 매일 하는 일은 딱 3가지
1. 계획 등록 — 계획 탭에서 다음 주 방문 계획을 금요일까지 등록
2. 방문 기록 — 방문 후 기록 탭에서 결과 입력 (홈 계획 카드의 [기록 쓰기]를 누르면 자동으로 채워져요)
3. 리드 관리 — 리드 탭에서 내 리드의 단계를 탭해서 변경 (컨택 → 데모 → 협의 → 계약)
기록을 남기면 같은 병원의 계획이 자동으로 '완료' 처리됩니다. 방문 못 간 계획은 홈에서 [연기/취소]로 정리해 주세요 — 안 하면 매일 아침 미기록 알림이 갑니다.
② 기록할 때 꼭 선택할 것
· 판매 카테고리 — 장비 판매 N-Care 중 선택 (필수)
· 판매 단계 — 데모 완료·협의중·제안 완료·계약 등. 퍼널·KPI가 전부 이걸로 집계되니 정확하게!
· 데모 노즐 사용량 · 배포 자료 — 데모/자료 전달 시 함께 입력
단계를 '계약'으로 저장하면 해당 병원 리드가 자동으로 계약·달성 처리됩니다.
③ 학회 · 세미나 모객
학회/세미나 탭 → 행사 카드의 [＋ 참석자 등록 (내 모객)]으로 내가 모객한 원장님을 등록하세요.
등록하는 순간 내 리드가 되고, 달성 목표가 내 KPI로 잡힙니다.
달성 목표 카테고리:
· 장비 판매 — 장비 미보유 병원의 구매 유도
· N-care_Basic / Standard / Pro / Premium — 가입·업그레이드 목표
④ 화면 한눈에 보기
홈이번 주 내 계획 + 내 KPI + 월별 누적. 하단 [더보기]에서 전체 메뉴
계획방문 계획 등록 (새 병원이면 리드도 자동 생성)
기록방문 결과 입력
리드내 리드 단계 관리 · 실패 리드 재컨택 추적
자료회사 공식 영업 자료실 (MA·C-Labs 업로드) — 항상 여기 있는 최신 자료로 배포
학회/세미나행사별 참석자·달성 현황, 내 모객 등록
흐름월별 영업 퍼널 (리드→제안→계약→입금)
KPI내 목표 대비 달성률, 목표 시기 임박 리드
N-CarePool 병원별 진행 단계(제팅교육→가입→업그레이드) 관리 · 우선 방문 후보
현황이번 주 팀 활동 모니터링
⑤ 자동으로 오는 메일
· 월요일 아침 — 이번 주 내 방문 계획 브리핑
· 금요일 오후 — 주간 활동 리포트 (내 실적 + 팀 현황)
· 매일 아침 — 방문기록 미입력 알림 (있을 때만)
· 수요일 아침 — 14일 이상 접촉 없는 내 리드 알림
· 목요일 아침 — 내 실패 리드 추적 (재컨택 시기 도래 알림)
· 금요일 아침 — 다음 주 방문 계획 등록 리마인더 (금요일까지 등록 원칙)
· 수시 — 새 영업 자료 등록 알림
알림을 받으려면 관리자에게 이메일 등록을 확인하세요. 리드에 방문 계획만 등록해도 방치 알림에서 빠집니다.
⑥ 폰에 앱처럼 설치하기
안드로이드 (Chrome) — 이 페이지에서 오른쪽 위 ⋮ → 홈 화면에 추가
아이폰 (Safari) — 하단 공유 버튼(⬆) → 홈 화면에 추가
카톡 안에서 열린 상태에서는 안 됩니다 — 오른쪽 위 메뉴에서 [다른 브라우저로 열기]를 먼저 눌러 Chrome/Safari로 연 다음 추가하세요. 추가하면 바탕화면 아이콘으로 앱처럼 실행되고 로그인도 유지됩니다.
⑦ 로그인이 안 될 때
· 이름은 사번 없이 실명 그대로 (예: 홍길동)
· PIN은 관리자(유영환)에게 받은 번호
· 인증번호 메일이 안 오면 스팸함 확인 → 그래도 없으면 관리자에게 이메일 등록 요청
· 화면이 이상하면 브라우저 새로고침 (카톡에서 열었다면 창을 닫고 다시 열기)
문의: 유영환 · 시스템은 계속 업데이트됩니다
